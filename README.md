# Study Performance Prediction and Study Recommendation System 🎓

## Project Overview
The Study Performance Prediction and Study Recommendation System is a Machine Learning based web application designed to predict student academic performance and provide personalized study recommendations.

## Objectives
- Predict student academic performance.
- Analyze student study habits.
- Identify areas requiring improvement.
- Provide personalized study recommendations.
- Improve learning efficiency.

## Technologies Used
- Python
- Flask
- Machine Learning
- Random Forest Algorithm
- HTML
- CSS
- Bootstrap
- SQLite

## Features
1. Student Details Input
2. Performance Prediction
3. Study Recommendation
4. Performance Analysis
5. Prediction History

## Input Parameters
- Daily Study Hours
- Attendance Percentage
- Previous Examination Marks
- Assignment Completion Percentage

## Output
The system generates an estimated academic score and personalized study recommendations.

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Open your browser and visit:

http://127.0.0.1:5000
